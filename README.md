# 아파트 실거래가 분석 (서울·경기)

국토교통부 공공데이터포털의 **아파트 매매/전월세 실거래가** 공식 API를 이용해 서울·경기 아파트 가격을
기간별/단지별/평형별로 분석하는 Streamlit 대시보드입니다. (네이버 부동산은 공식 API가 없어 크롤링이
이용약관 위반 소지가 있기 때문에, 대신 합법적인 국토교통부 공식 실거래가 데이터를 사용합니다.)

지금은 1단계(실거래가 수집 + 기간별/단지별/평형별 가격 추이)와 2단계(단지 세대수 + 세대수별 가격 상승률
분석)까지 구현되어 있습니다. 역세권·학군 분석은 이후 단계에서 추가됩니다.

## 처음 시작하는 방법

### 1. API 키 발급 (무료)

1. [data.go.kr](https://www.data.go.kr) 회원가입 후 아래 데이터들을 "활용신청"
   - [국토교통부_아파트 매매 실거래가 상세 자료](https://www.data.go.kr/data/15126468/openapi.do)
   - [국토교통부_아파트 전월세 자료](https://www.data.go.kr/data/15126474/openapi.do) (검색해서 찾기)
   - "공동주택 단지 목록제공 서비스" (검색해서 찾기) — 세대수 분석용
   - "공동주택 기본 정보제공 서비스" (검색해서 찾기) — 세대수 분석용
   - 승인은 보통 즉시~1시간 이내로 자동 처리됩니다. 마이페이지 > 개발계정에서 "일반 인증키(Decoding)" 값을 복사하세요.
     (네 개 모두 국토교통부/같은 계정이라 인증키 하나면 됩니다.)
2. 이 폴더의 `.env.example`을 복사해 `.env`로 이름을 바꾸고, `DATA_GO_KR_KEY=` 뒤에 방금 복사한 키를 붙여넣습니다.

### 2. 데이터 받기

**데이터_업데이트.bat**를 더블클릭하면 서울+경기 56개 시군구 전체, 최근 5년치 실거래가를 받습니다
(처음 한 번은 시간이 꽤 걸립니다 — 지역×월 조합만큼 API를 호출하기 때문입니다. 한 번 받아두면
`data/raw`에 캐싱되어 다음부터는 새로 생긴 달만 받습니다).

특정 지역만 빠르게 먼저 테스트해보고 싶다면 터미널에서:

```
python scripts/fetch_transactions.py --region 강남구 --months 12
```

주요 옵션:
- `--region 검색어` : 시도/시군구 이름에 검색어가 포함된 지역만 (생략 시 서울+경기 전체)
- `--months N` : 이번달 기준 최근 N개월만 (생략 시 최근 5년)
- `--start-ym / --end-ym` : 기간을 직접 지정 (예: `--start-ym 202301 --end-ym 202412`)
- `--skip-rent` : 전월세는 빼고 매매만
- `--force` : 캐시 무시하고 다시 API 호출

세대수 데이터는 별도로 받아야 합니다 (단지 수가 많아 시간이 좀 걸립니다):

```
python scripts/fetch_complex_master.py            # 서울+경기 전체
python scripts/fetch_complex_master.py --region 강남구   # 특정 구만 먼저 테스트
```

### 3. 대시보드 실행

**대시보드_실행.bat**를 더블클릭하면 브라우저에서 대시보드가 열립니다.

## 폴더 구조

```
config/lawd_codes.csv   서울 25개구 + 경기 31개 시군구 법정동코드(고정값)
data/raw/                API 원본 응답 캐시 (지역×연월별 XML, 단지 목록/기본정보 JSON)
data/processed/           정제된 데이터 (transactions.parquet, complex_master.parquet)
scripts/fetch_transactions.py     실거래가 수집 스크립트
scripts/fetch_complex_master.py   단지 세대수/기본정보 수집 스크립트
app/Home.py                       대시보드 첫 화면
app/pages/                        기간별 가격추이, 단지·평형별 비교, 세대수별 분석 등 세부 페이지
app/utils/name_match.py           실거래가 단지명 ↔ 국토부 등록 단지명 매칭 로직
```

## 참고 / 한계

- 평형대 구분은 전용면적(㎡) 기준 국토부 통계 구간(60/85/102/135㎡)을 사용합니다. 흔히 말하는
  "34평형"처럼 공급면적 기준 평형은 아파트마다 전용률이 달라 API 데이터만으로는 정확히 알 수 없어,
  전용면적 기준 구간 + 전용면적/3.3058 값을 참고용으로 함께 보여줍니다.
- 해제(계약 취소)된 거래는 집계에서 제외됩니다.
- **세대수 매칭**: 실거래가 API의 단지명과 국토부 공동주택 등록명은 표기가 다른 경우가 많습니다
  (지번 병기, 동 번호 병기, 표기 차이 등). 같은 시군구·법정동 안에서 정규화/유사매칭을 시도하지만,
  후보가 여럿이라 애매하면 틀리게 붙이는 대신 매칭하지 않습니다 — 세대수별 분석 페이지에 현재
  매칭률이 표시되며, 매칭 안 된 단지는 그 분석에서 제외됩니다.
